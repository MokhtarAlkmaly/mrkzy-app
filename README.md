# مركزي أوفلاين — مركز إنماء الأهلي الخيري (بدون إنترنت)

نسخة **تعمل دون إنترنت نهائياً** من نظام إدارة مركز تحفيظ القرآن الكريم
(بنين وبنات): سجل الطلاب والطالبات عبر كل الأعوام، المعلمون والمعلمات،
المتابعة الشهرية، المسابقات، الختمات، الشهادات والتكريم، المصاريف
والممولون، وقسم التدريب والتأهيل.

> هذه نسخة مستقلة من مشروع [mrkzy-app](https://github.com/MokhtarAlkmaly/mrkzy-app)
> السحابي — لا تحتاج Supabase ولا أي خادم ولا أي حساب سحابي.

## قاعدة البيانات: مجلد على الهاتف 📁

كل البيانات في مجلد واحد اسمه **`MrkzyDatabase`** على ذاكرة الهاتف،
داخله **ملف JSON لكل جدول** (`students.json`، `teachers.json`، …).
التفاصيل الكاملة في [DATABASE.md](./DATABASE.md).

- **المكان الافتراضي:** `Documents/MrkzyDatabase` — ظاهر في تطبيق «الملفات».
- يمكن نقل المجلد إلى **الذاكرة الخارجية** أو ذاكرة التطبيق من:
  **الإعدادات ← قاعدة البيانات المجلدية**.
- **النسخ الاحتياطي:** نسخ المجلد نفسه، أو زر النسخة الاحتياطية في
  الإعدادات (ملف JSON واحد + استعادة منه).
- **النقل لجهاز آخر:** انسخ المجلد والصقه في نفس المكان على الجهاز الجديد.

## المستخدمون المحليون 👥

- أول حساب يُنشأ على الجهاز (من صفحة الدخول ← «إنشاء حساب») يصبح
  **مسؤولاً** تلقائياً.
- بقية الحسابات تُنشأ من صفحة الدخول نفسها على نفس الجهاز، والمسؤول
  يديرها من **إدارة المستخدمين**: ترقية لمسؤول، حذف، مشاركة الاطلاع
  على البيانات (داخل الجهاز)، وإعادة تعيين كلمات المرور.
- كلمات المرور محفوظة كتجزئة SHA-256 مع ملح — لا تُحفظ نصياً أبداً.
- لا يوجد «نسيت كلمة المرور» بالبريد (لا إنترنت): المسؤول يعيد تعيينها.

## الميزات

كل صفحات النظام الأصلي تعمل محلياً: الطلاب، الحلقات، المتابعة الشهرية
(12 شهراً هجرياً)، روابط المعلمين (تعمل داخل التطبيق على نفس الجهاز —
المعلم يفتح بوابته من نفس الجهاز أو يُدخَل تقريره يدوياً من «الوارد»،
إذ لا خادم يشارك الروابط عبره)، الوارد والاعتماد، المسابقات، الختمات،
الشهادات، التكريم، المصاريف والممولون، الوسائط (ملفاتها داخل
`MrkzyDatabase/media_files/`), أسئلة الاختبارات من نص المصحف المدمج
(يعمل دون إنترنت)، والتدريب والتأهيل، والطباعة والتصدير (Excel/PDF).

الشارة في القائمة الجانبية قد تعرض حالة شبكة الجهاز، لكن **لا عملية
في النظام تحتاج الشبكة أصلاً**.

## التطوير

```sh
npm i
npm run dev        # خادم تطوير (على الويب تُحفظ البيانات في localStorage بنفس الصيغة)
npm run typecheck  # فحص الأنواع
npm run test:offline  # اختبارات القاعدة المجلدية والمستخدمين المحليين وبوابة المعلم
npm run build      # بناء الإنتاج (لا يحتاج أي متغيرات بيئة)
```

## بناء APK للأندرويد (GitHub Actions)

من تبويب **Actions** ← workflow «بناء تطبيق أندرويد (APK)» ← **Run workflow**،
ثم حمّل `app-debug.apk` من **Artifacts** وثبّته على الهاتف.
لا أسرار (Secrets) ولا إعدادات مطلوبة إطلاقاً.

معرّف التطبيق: `org.inmaa.mrkzy.offline` — يُثبَّت بجانب النسخة السحابية
دون تعارض.
