# مركز إنماء الأهلي الخيري — نسخة تعمل بدون إنترنت (Mrkzy-net)

نظام متكامل لإدارة مركز تحفيظ القرآن الكريم (بنين وبنات): سجل الطلاب والطالبات عبر
كل الأعوام، المعلمون والمعلمات، المتابعة الشهرية، المسابقات، الختمات، الشهادات
والتكريم، والمصاريف والداعمون، بالإضافة إلى قسم التدريب والتأهيل.

**هذه النسخة لا تحتاج إنترنت إطلاقاً**: لا خادم، لا Supabase، لا تسجيل دخول.
قاعدة البيانات عبارة عن **مجلد** تختاره أنت في **ذاكرة الهاتف** أو على **بطاقة الذاكرة (SD)**،
وكل جدول محفوظ فيه كملف JSON مقروء.

## كيف تعمل قاعدة البيانات (المجلد)

عند أول تشغيل تظهر شاشة **«اختر مكان قاعدة البيانات»**:

- **على أندرويد**: تفتح نافذة النظام لاختيار مجلد ← اختر «ذاكرة الهاتف» أو «بطاقة SD» ←
  أنشئ مجلداً جديداً باسم `MrkzyDB` (أو اختر مجلد قاعدة بيانات موجوداً) ← «استخدام هذا المجلد» ← «سماح».
  لا يحتاج التطبيق صلاحية «كل الملفات»؛ يحصل فقط على صلاحية دائمة لهذا المجلد (Storage Access Framework).
- **في المتصفح (حاسب)**: اختيار مجلد على الجهاز (Chrome/Edge)، أو التخزين الداخلي للمتصفح.

محتوى المجلد:

```
MrkzyDB/
├── mrkzy-db.json            ملف التعريف (إصدار الصيغة، العدّادات، آخر حفظ)
├── README.txt               شرح مختصر للمجلد
├── students.json            الطلاب والطالبات
├── year_data.json           بيانات الأعوام والدرجات
├── hifz_history.json        سجل الحفظ السابق
├── monthly_tracking.json    المتابعة الشهرية
├── teachers.json            المعلمون والمعلمات   (… وبقية الجداول — ملف لكل جدول)
├── backups/                 نسخ احتياطية يومية تلقائية (آخر 14 يوماً) + اليدوية
└── media/                   الصور والفيديوهات
```

- كل تعديل يُكتب في المجلد تلقائياً خلال أقل من ثانية (تُجمع التعديلات المتتالية في كتابة واحدة)،
  ويُحفظ أيضاً عند تصغير التطبيق.
- **الكتابة آمنة**: ملف مؤقت `.tmp` ثم استبدال، فلا يبقى ملف نصف مكتوب إن انقطعت الكهرباء أو أُغلق التطبيق.
  وإن تلف ملف يُحفظ نسخة منه (`*.corrupt-*.json`) ويُعرض تنبيه مع إمكانية الاستعادة من النسخ الاحتياطية.
- إن تعذّرت الكتابة (أُزيلت بطاقة SD أو سُحبت الصلاحية) يظهر شريط أحمر، وتبقى التعديلات في الذاكرة
  ويُعاد الحفظ تلقائياً.
- **نقل البيانات لجوال آخر**: انسخ المجلد كاملاً إليه، ثم اختره من «قاعدة البيانات ← تغيير المجلد».
- حذف التطبيق **لا يحذف البيانات** (المجلد خارج التطبيق) — بعد إعادة التثبيت اختر المجلد نفسه.

### شاشة «قاعدة البيانات» (`/database`)

| الميزة                          | الوصف                                                                                                                              |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| المجلد الحالي                   | المسار، حالة الحفظ، «حفظ الآن»، «إعادة القراءة من المجلد»، «تغيير المجلد»                                                          |
| محتوى قاعدة البيانات            | عدد السجلات في كل جدول/ملف                                                                                                         |
| النسخ الاحتياطية                | إنشاء نسخة داخل المجلد، تصدير ملف نسخة (مشاركة/تنزيل)، استيراد ملف، الاستعادة من أي نسخة (مع حفظ نسخة أمان تلقائياً قبل الاستبدال) |
| نقل البيانات من النسخة السحابية | لمرة واحدة فقط (تحتاج إنترنت أثناء النقل): بحساب النسخة السابقة نفسه تُنقل كل الجداول — والصور والفيديوهات اختيارياً — إلى المجلد  |

## الفرق عن النسخة السحابية

| الميزة                       | في هذه النسخة                                                                                                                                                           |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| تسجيل الدخول والحسابات       | غير موجود — مستخدم واحد على الجهاز                                                                                                                                      |
| إدارة المستخدمين و«عرض باسم» | أُزيلت (لا يوجد مستخدمون آخرون)                                                                                                                                         |
| المزامنة مع السحابة          | لا توجد — المجلد هو المصدر الوحيد. زر «تحديث من المجلد» يعيد قراءة الملفات                                                                                              |
| روابط المعلمين والمعلمات     | البوابة تُفتح **على نفس الجهاز** (زر «فتح» في `/teacher-links`) ويُسلَّم الجهاز للمعلم/ة، ثم تُراجَع الترسيلات في «وارد المعلمين والمعلمات». التقرير اليدوي يعمل كما هو |
| الصور والفيديوهات            | تُحفظ في مجلد `media/` داخل مجلد قاعدة البيانات                                                                                                                         |
| كل بقية الشاشات              | كما هي تماماً                                                                                                                                                           |

| الإعدادات                | `/settings`      | العام النشط، اسم المركز والتوقيعات، حالات الطلاب والطالبات، الأعمدة المخصّصة                                                                                       |

## البنية البرمجية (للمطورين)

```
src/offline/
├── folderDb.ts          المحرك: الجداول في الذاكرة + الحفظ المجمّع إلى المجلد + القيود الفريدة + الحذف المتسلسل + النسخ اليومية
├── schema.ts            الجداول (مطابقة لمخطط Supabase الأصلي في supabase/migrations) والقيم الافتراضية والعلاقات
├── query.ts             منشئ استعلامات متوافق مع supabase-js (select/insert/update/upsert/delete، المرشحات، التضمين)
├── rpc.ts               open_teacher_portal و submit_teacher_monthly محلياً
├── localClient.ts       عميل بنفس شكل Supabase (from/rpc/storage/auth) — يُصدَّر من src/integrations/supabase/client.ts
├── dbManager.ts         اختيار المجلد وحفظه وفتحه تلقائياً عند التشغيل
├── backup.ts            النسخ الاحتياطي والاستعادة والتصدير
├── cloudImport.ts       النقل لمرة واحدة من النسخة السحابية (تُحمَّل مكتبة Supabase عند الطلب فقط)
└── backends/            مخازن المجلد: أندرويد (SAF) / مجلد المتصفح / OPFS / IndexedDB / ذاكرة للاختبارات

android/app/src/main/java/org/inmaa/mrkzynet/FolderDbPlugin.java   الإضافة الأصلية (اختيار المجلد والقراءة/الكتابة)
```

بقيت شاشات التطبيق و`src/utils/storage.ts` كما هي تقريباً: العميل المحلي له نفس واجهة
Supabase، لذلك كل استعلام كان يذهب للسحابة يُنفَّذ الآن على ملفات المجلد.

## بناء ملف APK بدون كمبيوتر (GitHub Actions)

لا يحتاج أي أسرار (Secrets) في هذه النسخة:

1. ارفع المشروع إلى مستودع GitHub.
2. تبويب **Actions** ← workflow باسم «بناء تطبيق أندرويد (APK) — نسخة بدون إنترنت» ← **Run workflow**
   (ويعمل تلقائياً أيضاً مع كل دفع إلى `main`).
3. بعد انتهاء التشغيل (3–5 دقائق) حمّل `mrkzy-net-offline-apk` من قسم **Artifacts** — بداخله `mrkzy-net-offline.apk`.
4. ثبّته على الجهاز (فعّل «السماح بالتثبيت من مصادر غير معروفة» إن طُلب).

- معرّف التطبيق `org.inmaa.mrkzynet` واسمه «مركز إنماء بدون إنترنت»، فيمكن تثبيته **بجانب** النسخة السحابية.
- كل نسخ الـ APK موقَّعة بمفتاح ثابت (`android/app/mrkzy-debug.keystore`)، لذا تُثبَّت كل نسخة جديدة فوق
  السابقة مباشرة دون حذف التطبيق. (مفتاح للنسخ التجريبية والتوزيع الداخلي فقط، وليس للنشر في المتجر.)

## أسئلة الاختبارات ونماذج الاختبار

صفحة **أسئلة الاختبارات** فيها تبويبان:

| التبويب            | الوصف                                                                                                                                            |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **نماذج الاختبار** | توليد أسئلة الحفظ من نص المصحف حسب فئة الحفظ، بعدة نماذج (2–5) بمواضع مختلفة، ثم طباعتها (نموذج واحد أو الكل أو مفتاح التصحيح) أو حفظها في البنك |
| **بنك إضافي**      | بنك الأسئلة اليدوي: اختيار من متعدد / صح وخطأ / مقالي                                                                                            |

### صيغة السؤال

**اقرأ من قوله تعالى ﴿…﴾ إلى قوله تعالى ﴿…﴾**

بطول نحو **10 آيات** أو ما يقارب **5 أسطر** من مصحف المدينة (أقصرُهما) — في السور الطويلة
تُقصَّر الأسئلة حتى تبقى في حدود خمسة أسطر، ولا يقل السؤال عن آيتين ولا يتجاوز حدّ السورة.

### عدد الأسئلة حسب فئة الحفظ

| الفئة       | الأسئلة | التوزيع                                  |
| ----------- | ------- | ---------------------------------------- |
| جزء عمّ     | 3       | موزَّعة على الجزء 30                     |
| جزء تبارك   | 3       | الجزء 29                                 |
| 3 أجزاء     | 3       | سؤال لكل جزء                             |
| 5 أجزاء     | 3       | موزَّعة على أجزاء الفئة                  |
| 10 أجزاء    | 4       | موزَّعة على أجزاء الفئة                  |
| 15 جزءًا    | 5       | موزَّعة على أجزاء الفئة                  |
| 20 جزءًا    | 6       | موزَّعة على أجزاء الفئة                  |
| المصحف كامل | 6       | سؤال من كل 5 أجزاء (1–5، 6–10، …، 26–30) |

فئات الأجزاء الجزئية تُحسب افتراضيًا **من آخر المصحف** (28–30 لـ«3 أجزاء»، 26–30 لـ«5 أجزاء»،
وهكذا)، ويمكن تحويلها إلى **من أول المصحف** من خيار «نطاق الأجزاء» في نفس التبويب.

### بيانات نص المصحف

- الملف: `public/quran/uthmani.json` (~1.4 ميجابايت) ويعمل **دون إنترنت** داخل الموقع وداخل تطبيق أندرويد.
- يحتوي: نصوص الآيات الـ6236، وبداية كل جزء من الأجزاء الثلاثين، ورقم صفحة مصحف المدينة لكل آية.
- المصدر: نص تَنزيل العثماني عبر حزمة `quran-json@3.1.2` + أرقام الأجزاء والصفحات من `quran-meta` (رواية حفص).
- لإعادة توليده بعد تحديث النص: `npm run quran:extract` (المخطوط في `scripts/extract-quran-text.mjs`).
